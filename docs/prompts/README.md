Сохраняйте этот датированный снимок неизменным и редактируйте отдельную копию. Коммит снимка не меняет работающий бот.

## Как заменить тон сейчас

Проверено 24 октября 2026: опубликованный backend хранит этот блок в коде;
загрузка TXT через админского бота ещё не развёрнута. В интерфейсе нет ни
команды `/prompt`, ни кнопки «Настройки ИИ». Не отправляйте файл в рабочий
админский бот в ожидании автоматической замены.

1. Скачайте [исходный TXT](https://raw.githubusercontent.com/lebwa82/female_homelessness/main/docs/prompts/free-conversation-style-2026-10-24.txt)
   и сохраните копию, например `free-conversation-style-new.txt`.
2. Откройте копию в редакторе простого текста. Измените только тон и манеру
   свободного общения: обращение, длину ответов, стиль вопросов и формулировки.
   Сохраните как обычный `.txt` в UTF-8, не Word/RTF. Не добавляйте переписку
   клиенток, ключи или другие секреты.
3. Пришлите изменённый файл агенту проекта с заданием: «Замени только
   `SUPPORT_TONE` этим текстом, проверь регрессии сценариев и классификации,
   закоммить и запушь в main. Модель и остальные правила не меняй».
4. После проверки отдельно разрешите выкладку на Timeweb. Пока она не
   выполнена, бот продолжает использовать прежний текст. После выкладки
   проверьте несколько свободных ответов в своём тестовом разговоре;
   не используйте клиентские диалоги для тестирования.

Правка TXT сама по себе не обновляет production. На текущем этапе агент
переносит текст в `SUPPORT_TONE` в `app/agents.py`, проверяет его вместе с
остальными частями промпта и выпускает разрешённое обновление backend.
Незавершённые локальные правки редактора промпта при этом нельзя включать
в релиз автоматически.

Для отката сохранён исходный TXT и история Git. Откат тоже требует проверки
и разрешённого обновления backend; пользовательская история не сбрасывается.

## Что будет после внедрения редактора

В локальном черновике предусмотрен путь владельца в личном админском боте:
`/menu` → «Настройки ИИ» → «Скачать TXT» → редактирование → «Загрузить TXT» →
предпросмотр → «Применить». Это описание проекта функции, **не инструкция
к уже работающему интерфейсу**. Завершение, тестирование и первое развёртывание
редактора — отдельное изменение. После этого можно будет менять текст без
перезапуска сервиса.
