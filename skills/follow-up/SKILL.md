# Фолоуап

Один раз спросить, как сейчас по сравнению с моментом первого обращения:
«Лучше», «Примерно так же», «Сложнее». При отсутствии ответа допустимо одно
мягкое сообщение без вопроса и давления; больше не напоминать.

При «лучше» мягко предложить рассказать о помощи второго уровня. При «так же»
или «сложнее» предложить другую помощь или живого человека. Любой отказ принять.
